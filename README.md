## Deploy no GitHub Pages
1. Crie repositório: `llucasparanhos.github.io`
2. Suba todos os arquivos (index.html, style.css, main.js, pasta img/)
3. Settings → Pages → Branch: main → Save
4. Acesse: https://llucasparanhos.github.io
