## 🖥️ PORTFOLIO — 4 CASES PRINCIPAIS

### Case 1 — Redesign Check-in Wellhub
- **Problema:** Check-in frio, neutro, sem recompensa emocional
- **Insight:** Lucas tinha 340+ check-ins e o app não reconhecia o esforço
- **Solução:** Design emocional, gamificação leve, personalização
- **Reframing:** De botão → para ritual. De função → para celebração.
- **Benchmark:** Duolingo, Apple Fitness, TotalPass, Strava
- **Duração:** 2 semanas
- **Ferramentas:** Figma, Adobe CC

### Case 2 — Perfil Credenciados Kivid
- **Problema:** Lista com apenas contato disponível → usuário saía do app
- **Solução:** Página de perfil completa (nome, avaliação, mapa, horário, convênios)
- **Benchmark:** Doctoralia, Dr.consulta, Docway, Zenklub
- **Resultado:** Redução do tempo para localizar dados, mais agendamentos
- **Duração:** 3 semanas | **Ferramenta:** Figma

### Case 3 — Checkout Kivid
- **Problema:** Processo fragmentado, alto abandono, design desatualizado
- **Persona:** Adriana Santos, 56 anos, professora, classe C/D
- **Solução:** Tudo em uma página, preenchimento via CPF, resumo dinâmico
- **Resultado:** +15% conversão, -20% abandono de carrinho
- **Duração:** 10 semanas | **Ferramentas:** Figma, Clarity

### Case 4 — Avaliação NPS Kivid
- **Problema:** Nenhum canal de feedback → time sem dados de satisfação
- **Solução:** Fluxo simples, emojis para expressão emocional, qualitativo opcional
- **Benchmark:** Doctoralia, Dr.consulta, Docway, Boa Consulta
- **Resultado:** Canal estruturado criado, dados NPS acionáveis para o time
- **Duração:** 2 semanas | **Ferramenta:** Figma
